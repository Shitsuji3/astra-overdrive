# プレイヤー破壊演出・溜め突き拡大

ユーザー依頼：死亡時に壊れるアクション。溜め突きの長さ・上下範囲を1.5倍。
基準：Opus5のSTART MISSION削除・公開済み2386386。削除作業は変更していない。

## 変更

- game.js：死亡時は即座にdeadへ移行して戦闘停止。deathイベントで既存死亡音とリザルト音量へ移行する。deathFxを1.15秒だけ進め、death-readyイベントで結果画面を表示。既存Rキーの即リトライも可能。リトライ時は演出を破棄し、古い結果イベントを発生させない。被弾で死亡したフレームの後続戦闘処理も止める。
- render.js：主人公をオフスクリーンで描画し、実際の装甲画像を12片に分割。最初の0.16秒に発光、破片の飛散・回転、エネルギーリングと8方向の光、減衰で消える。落下死の場合は画面内の床付近で表示。演出軽減では移動・回転・発光を抑え、8方向の光を省略。素材の再生成なし。
- ui.js：deathでは音のみ、death-readyでリトライ画面。BGMは従来のリザルト音量設定を使用。
- assets/saber-rig.js：thrustFxの形状をセイバーの手元から1.5倍。球の位置・半径、槍の長さ90→135・厚み・膨らみを拡大。blade/sweepも同じ形状を読み、表示と当たりの長さを同期。
- game.js：溜め突きの上下判定pad9→13.5。リグが無い場合の前方範囲110→165、上下範囲も1.5倍。通常斬りと斬り上げは維持。威力4.5×4、時刻、踏み込み、チャージ時間、SEは変更なし。

## 検証

- npm test：135件合格。死亡イベントの一度だけの完了、戦闘停止、リトライ後に古い結果を出さないことを追加検証。
- qa/player-break-thrust.cjs：基準2386386と比較し、可視73姿勢の手元→刃先1.5倍、球の縦横・槍の長さと厚み1.5倍を確認。ブラウザーで演出中は結果を隠し、進行・終了・リトライが正常。左右の上下範囲で12px先は当たり、30px先は範囲外。エラー0。
- 既存の実戦テスト：180px先の敵に当たり、260px先・後方には当たらない。近距離は従来どおり4回のヒット。
- 画像：qa/player-break-thrust/death.png、thrust.png。QA用に固定した時刻の画像。
