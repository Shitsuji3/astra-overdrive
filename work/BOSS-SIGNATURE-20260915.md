# ボスの固有モーション：COILHEADとSPARKWIDOW（2026-09-15）

ユーザー依頼：「各ボスに特殊なモーションが欲しいです。案を出してくれるかい？」

8体分の案を出した。ユーザーの返事は「3の蜂と7の蜘蛛からお願いします」。

「新しい攻撃として行動ループに足すか、見た目だけ派手にするか」には返事がなかった。そのため、案のとおり新しい攻撃として作った。ほかのボス、既存の8種の攻撃、数値は変えていない。

## COILHEAD（磁頭・蜂）「急降下の毒針」 `dive`

| 段階 | 中身 |
|---|---|
| 予兆 | 0.90秒×テンポ0.95。上向きの矢印3つと、浮上する高さまでの点線。「▸ DIVE STING」 |
| 浮上 | 0.45秒で床から150px上へ。浮きながらプレイヤーの真上へ寄る（260px/秒） |
| ホバー | 0.55秒。真上で追う。床に照準の輪（青）。**最後の0.18秒は位置を固定**し、輪は赤くなって括弧が付く |
| 落下 | 2600px/秒²で固定した位置に落ちる。上に光の筋。体に触れると従来どおり2ダメージ |
| 刺さる | 床に電撃を左右へ1本ずつ（威力1、240px/秒、0.75秒で消える）。画面が揺れる |
| もがく | 1.0秒その場で動けない。「▽ OPEN」を表示。そのあと行動ループどおりの休み0.9秒 |

- **行動ループ：** 5手の最後に足して6手にした（wall→volley→dash→mines→ring→**dive**）。
- **浮いている間の反撃：** ボスの当たり判定も一緒に上がるので、斬り上げで迎え撃てる。
- **向き：** 浮上してからは向きを変えない。真上で追っている間に絵が左右に反転しないようにするため。

## SPARKWIDOW（火寡・蜘蛛）「糸渡りの丸鋸」 `swing`

| 段階 | 中身 |
|---|---|
| 予兆 | 0.90秒×テンポ0.65。天井の支点までの糸（赤い点線）と、振り子の軌道の弧。「▸ SILK SWING」 |
| 登る | 0.40秒で、自分の側の糸の端（支点から真下より55度）まで引き上がる |
| 振り子 | 0.90秒で反対側の55度まで。支点はアリーナ中央、上から36px、糸の長さ250px。**最下点で足が床をかすめる**（体の下端が床から2px上）。立っていると体に当たって2ダメージ。ジャンプで越える |
| 手を離す | 反対側で糸を離して落ちる。着地で跳躍の衝撃波は出さない |
| 丸鋸 | 着地と同時に左右へ1枚ずつ（威力1、270px/秒、半径9）。0.75秒で折り返して戻り、1.5秒で消える。セイバーで消せる |

- **行動ループ：** 6手が上限（テストで決まっている）なので、2回あった射撃（volley）のうち最後の1回を糸渡りに入れ替えた（dash→volley→wall→dash→mines→**swing**）。
- **アリーナとの関係：** アリーナの幅はどのステージも440pxで、振り子は中央から左右205pxの範囲に収まる。

## 実装

- **`game.js`：**
  - `combat.bossPatterns` に `dive`／`swing` を追加。
  - 数値は `combat.bossDive`／`combat.bossSwing`、支点の位置は `combat.bossSwingAnchor`。
  - `_bossFire` で `b.fly`（重力を止める）と `b.move`（段階の状態）を立てる。
  - `_bossMove` が段階を1フレームずつ進め、終わるとタイマーを0にして休みへ移す。
  - 技が終わるまで、パターンの時間切れで休みに移らないようにした。
  - 休み・次の手・撃破で `move`／`fly` を片付ける。空中で倒されると床へ落ちる。
  - 弾に `turn` を持たせると、残り寿命がその値になった時点で1回だけ折り返す（丸鋸用）。
- **`assets/bosses.js`：** 2体の行動ループと紹介文。技の一覧 `catalogue` に2つを追加。
  - 旧来の8種の並び `combat.bossPatternOrder` には足していない。WARDENの基準値を作るツールと古いQAが、あの8種の並びを前提にしているため。
- **`render.js`：**
  - 技の表示名、2つの予兆の絵、照準の輪と固定、落下の筋、刺さった所の火花、糸の線、丸鋸の絵。
  - もがいている間の「OPEN」表示。
  - 体の傾き（`bossPose`）。蜂は毒針が絵の右端にあるので、絵の向きのまま0.6ラジアン回すと針が下を向く。蜘蛛は糸の角度の0.55倍だけ傾ける。
- **README：** ボスの節に2体の固有技を追記。

## 見比べて直したこと

- **傾けると黒い斜めの板が出た。** 切り抜き画像の一番下に工場の床が残っていて、体を傾けるとそれが一緒に傾いたため。
  - 床の帯の高さを画像で測った。COILHEADは明るい床の縁とその下の床板で336行中の下12行、SPARKWIDOWは床板と黄黒の縞で290行中の下40行。
  - 技の最中に傾いている間、または宙に浮いている間は、この帯を描かない（`BOSS_FLOOR_BAND`）。
- **ホバー中に絵が左右に反転しうる。** 向きを浮上した時のまま固定した。
- **丸鋸が白い丸にしか見えなかった。** 明るい刃に暗い縁、ボスの色の縁取り、床に散る火花にした。

## 確認

- **`npm test` 152件合格。**
  - `tests/bosses.test.cjs` に6件追加：
    - 蜂が浮上・追尾・固定・落下・刺さり・もがきを順にこなし、固定後は追わず固定位置に落ちる。電撃は左右に1本ずつ。
    - 真下に残ると当たり、固定後に避けると体は当たらない。
    - 蜘蛛がアリーナの外に出ず、最下点で床をかすめ、反対側で離し、跳躍の衝撃波を出さずに着地し、丸鋸を左右に2枚投げる。
    - 丸鋸は1回だけ折り返し、180px以上進んでから戻る。
    - 振り子の最下点に立っていると当たる。
    - 技の途中で倒すと床に落ちる。
  - 「どの攻撃も何かを起こす」のテストは、2つの技について「宙に浮く」ことを確かめる形にした。
- **`qa/boss-signature-moves.cjs`（新規）：** 実際の画面で、2つの技の全段階を通した。
  - アリーナの外に出ない。
  - 描画がゲームの状態を変えない。
  - 演出を控えめにする設定でもエラー0。
  - 撮影：`qa/boss-signature/dive.png`、`swing.png`、記録：`verification.json`。
- **`qa/boss-attack-fx.cjs`：** 既存8種の攻撃が、8体とも変更前（c3f87c1）と一致（64件）。
- **リリース用ビルド：** 合格。
- **ブラウザ起動テスト：** 結果が不安定だった。
  - 作業中、このPCでは他のアプリ（Street Fighter 6 など）がCPUを115%使っていた。
  - 失敗した場所は毎回違い、どれもボスが出る前の段階だった（キー入力での移動、ジャンプ、出撃）。
  - 今回の変更を入れる前のコード（14cb13a）を別のポートで配信し、変更前と変更後を交互に3回ずつ流した。変更前は3回中1回合格、変更後は3回中2回合格（18項目）で、どちらも同じように落ちた。
  - ゲーム自体は、ヘッドレスのブラウザで1秒あたり165フレーム、ゲーム内の時間は実時間どおりに進んでいた。1フレームの処理は約0.015ミリ秒、描画は約0.5ミリ秒で、急降下中も変わらない。
  - 以上から、今回の変更による失敗ではなく、マシンの重さでテストの待ち時間に間に合わなかったものと判断した。

## 見つけたが直していないこと

- **ボスがプレイヤーに背を向けている（前からの挙動）。**
  - 自前の絵を持つボスの画像は左向きに描かれている。
  - 描画は「プレイヤーが左にいると左右反転する」作りで、これは右向きに描かれた共通フレーム用のもの。
  - そのため、COILHEADやWARDENはプレイヤーと反対を向く。自前の絵を持つ7体すべてに関わるので、ユーザーの判断を待つ。
- **切り抜き画像に工場の背景が残っている（前からの状態）。**
  - `assets/bosses/README.md` に記載のとおり。
  - 技の最中は床の帯だけを消している。脚の間の背景は残っている。

## 調整するには

- 高さ、時間、速さ、威力 → `game.js` の `combat.bossDive`／`combat.bossSwing`、`combat.bossPatterns` の `tell`
- ループのどこで出すか → `assets/bosses.js` の `routine`
- 傾きの量、床の帯 → `render.js` の `BOSS_STING_TURN`、`bossPose`、`BOSS_FLOOR_BAND`
