# ステージ選択を地図の盤面にした（2026-09-12）

ユーザー依頼：ロックマンXのステージ選択画面の画像を添えて「では、こんな感じでステージを
選んで進めるようにしてよ」。

結果：縦に並んだリストをやめ、**都市の地図をボスの顔パネルが囲む盤面**に作り直した。
参考画像は配置の考え方だけを取り、絵・配色・記号はこのゲームのものを新しく描いた。

## 1. 盤面

```
      01      02    BOSS RUSH    03      04        ← 上段（中央は連戦）
      ┌──────────────────────────────────┐
      │            都市の地図             │
      └──────────────────────────────────┘
      05      06                07      08        ← 下段（中央は空ける）
      ┌──────────────────────────────────┐
      │ いま合わせているミッションの詳細   │
      └──────────────────────────────────┘
```

参考画像と同じで、上段4枚＋中央、下段は真ん中を空けて左右に2枚ずつ。中央の枠は参考では
主人公の紋章だったが、ここは **BOSS RUSH**（9番目の連戦）を置いた。最後に行く場所が真ん中に
あるのは地図として筋が通る。

各パネルはボスの顔写真、番号、ステージ名、記録（CLEAR / NO RECORD）。顔は今までの
240pxの資料写真をそのまま使っている。連戦だけは顔が1つに決まらないので、
`x8` を囲む円の紋章を描いた。

## 2. 地図

外部画像は増やしていない。**SVGをその場で組み立てている。** 中身は、都市が乗っている台座、
台座の中に切り抜いた方眼、手で置いた区画14個、中心から各地へ伸びる経路、そして
ミッションごとのピン。

ピンの位置は `assets/stages.js` の `site: { x, y }`。地図の枠は900x230で、
エンジンやUIが座標を持たないのは他のステージデータと同じ考え方。

| ステージ | 位置 |
|---|---|
| 1 SIGNAL YARD | 96, 104（西の端） |
| 2 TIDAL REFINERY | 180, 178（南西の岸） |
| 3 MAGNET SPINE | 238, 60（北の尾根） |
| 4 CINDER FLATS | 368, 194（南の平地） |
| 5 ANVIL DEPTH | 596, 188（南東の坑） |
| 6 VOID CHOIR | 452, 48（北の聖堂） |
| 7 FILAMENT RUN | 664, 70（北東） |
| 8 CROWN VAULT | 800, 122（東の端） |
| 9 BOSS RUSH | 450, 118（中心） |

合わせているミッションのピンだけが珊瑚色になり、輪が広がる。地図は画面を開いたときに
一度だけ組み立てて、あとは光らせ方だけ変える。カーソルを動かすたびに作り直すと
輪の動きが毎回頭から始まってしまうため。

**ピンは押せる。** 押すとそのミッションにカーソルが移る。地図から選ぶ道と
パネルから選ぶ道の両方がある。

## 3. 操作

- **←→↑↓** カーソル移動。**画面上の位置で動く。** 縦に並んだ列の何番目、という
  持ち方をやめ、いま描かれている矩形の中心から「その方向にあっていちばん近いもの」を選ぶ。
  正面にあるものが横にずれているものより優先される。その方向に何も無ければ反対の端へ回る
- **Enter** 出撃
- **Esc** タイトルへ戻る
- クリック／タップ：パネルで出撃、地図のピンで選択

画面位置で動くようにしたのは、狭い画面だと並びが変わるからだ。地図を隠して
タイル9枚の格子になったとき、机上の並びのまま動くと見えている配置と合わなくなる。

格子になり、9枚と詳細欄が収まる。実測で、はみ出しもページのスクロールも無い。

## 5. 検証

`npm test` 全93項目合格。追加1項目で、全ミッションが地図上の位置を持ち、枠の内側に収まり、
ピン同士が40px以内に重ならないこと、連戦がちょうど1つであることを見ている。

`qa/select-screen.cjs` を新規追加した。4つの画面サイズで選択画面を開き、次を確認する。

- ミッションが9枚出ること
- 地図が出る／隠れる条件どおりであること
- カーソルを動かすと地図のピンがついてくること。光るのは常にちょうど1つ
- 地図のピンを押すとそのミッションにカーソルが移ること
- パネルを押すとそのステージが実際に始まること
- 例外が出ないこと

`tests/browser-smoke.cjs` 17項目・`tests/browser-mouse.cjs` 12項目合格。
`qa/stage-playthrough.cjs` は9ステージすべてを選択画面から起動して走破し、記録が
選択画面に載ってリロード後も残ることを確認する。セレクタを `.stage-row` から
`.stage-node` に直した。

公開用ビルドは44ファイル 8.67MB で変わらず。**地図は画像ではないので容量は増えていない。**

図は `qa/select-screen.png`（4サイズ×カーソル2状態）。
