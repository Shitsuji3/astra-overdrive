# COILHEADを「普段は飛んでいるボス」に（2026-09-16）

ユーザー依頼：「良い特徴になるので、蜂のボスは基本飛んでるのでいいですね。たまーに降りてくるくらいで良いです。これを考慮して、攻撃モーションを修正してください。」

## 変わったこと

- **登場と普段の高さ：** 登場した時から宙に浮いている。攻撃の合間は床から90px上を飛ぶ（`assets/bosses.js` の `flies: { cruise: 90 }`）。
  - この高さなら、立っているプレイヤーの頭上を通り抜ける（体の下端220px、プレイヤーの頭270px）。
  - ジャンプしながらの射撃・セイバーと斬り上げは届く（ジャンプの頂点でプレイヤーの頭は186px）。
- **移動：** 空中のまま横に飛んで移る。高さは毎秒160pxで変わる。飛んでいる間、絵はゆっくり上下し、床に影を落とす。
- **攻撃（すべて空中から）：**
  - 壁弾：床から縦に並ぶ弾の壁
  - 地雷：床に落ちる
  - 全方位弾：体の周りに出る
  - 射撃（volley）：空中からプレイヤーに向けて斜め下に撃つ。扇の真ん中がプレイヤーの胸に届くよう、全体を傾ける
  - 突進（dash）：真横に飛ぶと頭上を素通りするので「低空滑空（SWOOP）」にした。元の突進と同じ速さ・長さで横に進みながらU字に沈む。途中で一番低くなり（床から24px上、体の下端286px）、立っていると当たる。ジャンプで越えられる（体の上端236px、ジャンプの足は226px）。予兆はU字の軌道の線。
- **降りてくるのは急降下の毒針だけ：** 刺さってもがく1秒と、その後の休み0.9秒の間は床にいる。次の行動に移ると同時に飛び立つ。

## 実測（`qa/coilhead-flight.cjs`、プレイヤーは静止）

- 1ループ（6手）と次の手の出だしまでで26.5秒。**空中にいた時間は92.8%**。
- 壁弾・射撃・滑空・地雷・全方位弾・急降下は、すべて高さ90pxで出た。
- 滑空の一番低い所：体の下端286px（9.0秒時点）。
- 描画がゲームの状態を変えたか：変えていない。ページエラー0。
- 画像：`qa/coilhead-flight/loop.png`（各攻撃の瞬間、滑空の底、刺さった瞬間、着地後の休み、飛び立ち）。

## 実装

- **`game.js`：**
  - `combat.bossFlight`（高さを変える速さ `climb`、滑空で一番低くなる高さ `swoopClear`）を足した。
  - 登場時に `flies` を持つボスは空中に置く。
  - 技の最中でなければ、巡航高度（着地中は床）へ向かう。
  - 急降下の着地で `grounded` を立て、休みの間は床にいる。次の手で `grounded` を下ろして飛び立つ。
  - 射撃の傾きと、滑空への置き換えは、ボスが今飛んでいるか（`b.fly`）で決める。**床にいる時の元の8種の攻撃は変わらない。**
- **`render.js`：** 飛行中の上下の揺れ、空中の物に落ちる影（糸渡りの蜘蛛にも付く）、滑空の予兆と表示名「SWOOP」、滑空の光の筋。切り抜きに残る床の帯は、浮いている間はいつでも描かない。
- **`assets/bosses.js`：** `flies` の説明、COILHEADの設定、紹介文。
- **README：** COILHEADの説明。

## 確認

- **`npm test` 156件合格。**
  - `tests/bosses.test.cjs` に4件追加した。
    - 空中で登場し、立っているプレイヤーの頭上・ジャンプの届く高さを飛ぶ
    - 40秒通して、床にいるのは急降下の刺さりと休みの間だけで、全体の2割未満。飛び立って1秒以内に巡航高度に戻る
    - 空中の突進は滑空で、途中で立っているプレイヤーの高さまで下がり、ジャンプで越えられ、元の高さに戻って空中で休む
    - 空中の射撃はプレイヤーの胸に向かう。床の上では元の平らな扇のまま
  - 「どの攻撃も何かを起こす」テストは、空中の突進については滑空を認める形にした。
- **`qa/boss-attack-fx.cjs`：** 比較のときだけボスを床に置く形に直した。床の上での元の8種の攻撃は、8体とも変更前（c3f87c1）と64組一致。描画256枚、エラー0。
- **`qa/boss-signature-moves.cjs`：** 急降下と糸渡りは全段階を通過（急降下は巡航高度から始まる）。
- **その他：** ブラウザ起動テストは1回目で18項目合格。build:ci成功。

## 調整するには

- 普段の高さ → `assets/bosses.js` のCOILHEADの `flies.cruise`
- 高さを変える速さ、滑空の深さ → `game.js` の `combat.bossFlight`
- 滑空の速さと長さ → COILHEADの `dashSpeed`／`dashHold`（元の突進の値をそのまま使っている）
