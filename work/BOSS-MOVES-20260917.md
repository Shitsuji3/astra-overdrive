# 全ボスの攻撃を、見た目に合う固有技に入れ替え（2026-09-16〜17）

ユーザー依頼：「全てのボスの見た目に合う攻撃モーションを今の攻撃モーションと入れ替えてください。君のセンスに任せるよ。」

- **行動ループ：** 8体とも新しい技で組み直した（4〜6拍、隙は最短0.60秒のまま）。
- **SPARKWIDOWに「SAW TOSS」を追加した理由：** SPARKWIDOWから「その場で撃つ技」（壁弾・地雷・扇状射撃）が抜けた結果、ループの6割しかその場に留まらなくなり、`qa/boss-motion.cjs` の基準（7割）を下回った。見た目に合う「その場から投げる技」を足し、突進を2回から1回に減らして73%にした。
- **ボスの向き：** 自前の絵を持つボスが、プレイヤーに背を向けて描かれていた（前回「判断待ち」にしていた件）。元絵はASHMAWとNULLPRIESTだけが右向きで、ほかは左向き。ボスごとに元絵の向きを持たせ、全員がプレイヤーの方を向くようにした。
- **共通の8種の攻撃：** 仕組みはゲームに残してあり、変更前と同じ動きかを引き続き測っている。どのボスのループにも入っていない。

## 描画（`render.js`）

- **体の動き：** 技ごとに、しゃがむ・のけぞる・振り下ろす・踏み込む・反動・叩きつけ・空中・溜め・回転のポーズを付けた。溜めの間は途中まで構え、技で残りを動く。ポーズは次のポーズへ滑らかにつながる。頭を上げる時は後ろ足、下げる時は前足を軸に傾く。空を飛ぶボスは体の中心が軸。
- **予告：** 技ごとに、来る場所へ線・輪・枠・矢印を出す。床沿いの攻撃は赤、頭上の攻撃と軌道は橙。技名は画面下に表示する。
- **弾と地形の攻撃の絵：** 砲弾、投げ刃、水滴、針、岩（ASHMAWのものは溶岩）、虚空の玉（割れる玉は脈打ってひびが入る）、火の粉、黒曜石の破片。水柱、落雷、炎、燃える床、ビーム、牙、尾の薙ぎ、着地の印。地形の攻撃は、当たるようになるまで予兆だけを描く。
- **技に付く効果：** 大砲の発射炎、突進の風切り線、口から床への炎、噴出口の火、煙突の煙、帯電、消える時と現れる時の裂け目、ビームの溜め、尾の回転の軌跡、丸鋸の火花など。
- **切り抜きの床：** 切り抜き画像に残る床の帯を測り、TIDEBREAKER（下5行/301）・NULLPRIEST（4/338）・GRAVELOCK（8/264）を追加した。跳んでいる間とポーズ中は描かない。これで、跳躍中に足元へ床の線が付いてこない。

## ゲームの仕組み（`game.js`）

- `BOSS_MOVES`：技ごとの台本。`b.move` に進み具合を持ち、終わったらボスを休みに戻す。
- 地形の攻撃（`kind:'hazard'`）は長方形の当たり判定を持つ。当たるようになるまでは予兆だけで、当たっても消えず、セイバーでも切り払えない。印（`harmless`）は当たらない。
- **落石：** 上で止めて待たせ（`hold`）、時間が来たら落とす。
- **曲射：** 狙った床の位置へ、決めた時間で落ちる。途中の足場を通り抜けて床に落ちる（`floorOnly`）ので、印や燃える床の上に必ず落ちる。
- **割れる玉：** 決めた時間に割れる（`split`）。
- **NULLPRIESTが消えている間**（`phaseOut`）：自機の弾・セイバー・体当たりのどれも当たらない。

## 確認

- **`npm test` 169件合格。** `tests/bosses.test.cjs` を23件から36件にした。
  - 自分の体の技だけを使い、ボス同士で共有しない。1体3技以上
  - どの技も時間内にアリーナの中で休みに戻り、床に立って終わる（飛ぶボスは除く）
  - 地形の攻撃は、当たるようになってから当たり、当たっても消えない
  - 技ごとの確認：
    - WARDENの衝撃波は両端から来る。岩は待ってから印の上に落ちる
    - TIDEBREAKERの刃は低い・高いの順
    - OBSIDIAN CROWNのビームは頭上→足元
    - NULLPRIESTは消えている間に当たらない。止まっているプレイヤーの向こう側に出る。玉は8つに割れる
    - ASHMAWの溶岩弾は燃える床の上に落ちる
    - COILHEADは巡航高度のまま撃つ
    - 跳躍系4技は床に着地する
    - SPARKWIDOWは投げる間動かず、丸鋸は床沿いに行って戻る
  - 前からあったテストは、2件を新しい技に合わせて直した（WARDENの手持ちの比較、歩きの判定）。「どの攻撃も何かを起こす」は、新しい技も最後まで動かして確かめる形にした。
- **`qa/boss-attack-fx.cjs`：** 共通の8種の攻撃は、8体とも変更前と64組一致。描画256枚、エラー0。
- **`qa/boss-signature-moves.cjs`：** 急降下と糸渡りは全段階を通過。

## 見つけたが直していないこと

- **`tests/browser-gamepad.cjs` が「失敗画面でAを押すとリトライ」の確認で毎回失敗する。**
  - 変更前のコード（別ポートで配信）でも同じように失敗したので、今回の変更が原因ではない。
  - 原因：倒れた後の演出で、失敗画面が出るまで約1.1秒かかる。テストはその前にAを押している。
  - ゲーム自体は正常。失敗画面が出てからAを押せば、正しくリトライする。
  - 直し方：テストで失敗画面が出るのを待ってから押す。別の作業として提案済み。

## 調整するには

- 技の中身（弾の数・速さ・距離・時間）→ `game.js` の `BOSS_MOVES`
- 溜めの長さと技の長さ → `game.js` の `combat.bossPatterns`（ボスごとの `tempo` で溜めを伸縮）
- どの技をどの順で、どの距離から、隙を何秒 → `assets/bosses.js` の `routine`
- ポーズの大きさ → `render.js` の `BOSS_POSES`、溜めのポーズ → `BOSS_TELL_POSES`
- 予告の描き方 → `render.js` の `BOSS_TELLS`、弾の絵 → `BOSS_SHOTS`、地形の攻撃の絵 → `bossHazardShape`
- 元絵の向き → `render.js` の `BOSS_DRAWN_RIGHT`
