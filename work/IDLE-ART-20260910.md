# 待機絵の描き直し

内蔵 image_gen ツールを使用。素材: `assets/player-idle-v2.png`。参照は既存プレイヤーの `qa/saber-motion-v2/source-cell.png` と、ユーザーの `スクリーンショット 2026-09-09 211417.png`。

生成画像は元ファイルを残し、RGBAのままゲームへコピー。1254×1254、alpha 0〜255。画像を書き換えず、ゲーム側でキャラクターの範囲を切り出し、48pxの高さで表示する。

胴体・腰・手足を別の絵から合成した待機表示を、一体で描いた専用スプライトへ置換。上体と腕は一緒に小さく呼吸し、下端は固定する。射撃・走行・セイバーの素材はこの変更の対象外。

最終プロンプト（内蔵ツール）:

```
Create one production-ready transparent pixel-art idle game sprite, full body. Reference image 1 defines the SAME existing blue/ivory robot hero: cobalt and azure segmented armor, ivory helmet fin sweeping backwards, cyan visor/face looking screen RIGHT, small amber circular chest reactor and ear light, cyan short scarf streaming left, sleek blue armored boots. Reference image 2 defines ONLY the standing pose and proportions. Repaint the blue hero as a cohesive single illustration in that pose, NOT a collage of parts. Torso and pelvis face mostly toward the viewer; the head looks to the character's front, screen RIGHT, never at the viewer. Legs comfortably open shoulder width, feet flat and pointing slightly outward, pelvis high, weight balanced, knees only softly flexed. Heroic agile upright stance, no deep squat, no bow legs, no bulky diaper-shaped pelvis. ANATOMICAL RIGHT hand on screen LEFT is an ordinary silver/blue gloved fist bent upward near the upper chest, tucked close to the body, below eye level, not flexing a huge bicep. ANATOMICAL LEFT forearm on screen RIGHT is the single blue buster with orange muzzle, held compactly near the waist angled gently forward/down. Exactly one buster and one normal fist. Match the original hero's slender athletic proportions, integrated hip armor, coherent cel-shaded pixel clusters, dark navy outlines, crisp blue midtones and ivory highlights. PS1-quality action sprite, clear at 50 pixels tall, no realistic textures or gradient glow. Entire character including both boots and scarf fully visible, centered with generous transparent margin on a square canvas. True alpha-transparent background, no floor shadow, no text, no border, no extra pose, no checkerboard pattern. Preserve the original hero identity and color design.
```

検証: npm test合格。実描画202姿勢で新規スプライト使用、腰の継ぎ目連続、足元固定、0.7pxの呼吸変位、ページエラー0を確認。左右の4位相および実ゲーム画面を確認。
