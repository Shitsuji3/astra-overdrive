# スマートフォン操作の再設計 — 2026-10-02

基準：ローカルmain e69a89f（8ボスの追加16技を含む）。親が直接設計・実装・検証、サブエージェントなし。

旧配置は方向と攻撃の9ボタンが画面下へ横一列、幅38〜44px。左スティック・右アクションへ変更した。配置の参考は[Activisionの公式モバイル操作説明](https://blog.activision.com/es/call-of-duty/2019-10/Getting-a-Grip-on-the-Call-of-Duty-Mobile-Controls)と[Warzone Mobileの公式操作案内](https://www.callofduty.com/uk/en/blog/2024/03/call-of-duty-warzone-mobile-complete-control-plus-customization-controller-options)。世界共通の規格を意味するものではなく、左右の親指に役割を分ける一般的な配置を、この2Dアクションへ適用した。

## 操作

| 場所 | 動作 |
|---|---|
| 左下のスティック | 8方向入力。左右で移動、上下で特殊技。中心は入力しない。指を離さず方向を切り替えられる |
| 右下・下の大ボタン | ジャンプ。長押しで既存の高いジャンプ |
| 右下・左のボタン | ダッシュ |
| 右下・上のボタン | バスター。離すと1発（現在のゲーム仕様を維持） |
| 右下・右のボタン | セイバー。タップで斬撃、保持→READYで離すと溜め突き |
| スティック上＋セイバー | 既存の斬り上げ |
| 地上でスティック下＋セイバー保持→離す | 既存の扇状弾。最大3段 |
| 右上 | ポーズ、対応ブラウザーのみ全画面 |

横持ちは半透明の操作を左右の下隅に配置。縦持ちはゲーム画面と下部の操作を分離し、横持ち案内を表示。ノッチとホームインジケーターのsafe-areaに対応。ボタン名とアイコン、押下色を表示する。設定で85〜125%に調整・保存でき、狭い画面では上限を制限して左右の重なりを防ぐ。検証した最小幅320pxでは全アクション・ユーティリティの押下領域44px以上。

## 入力の契約

- `touch-controls.js` が各pointerIdの所有者を保持。指を1本離しても、別の指の入力を解除しない。同一ボタンを2本で押した場合も最後の1本まで保持する。
- スティックは固定中心、10%のデッドゾーン、斜め入力に対応。キャプチャにより枠外へ動かしても指を追う。
- アクションは14pxまでの指のずれを許容。別のアクションへ滑らせると切り替える。
- `game.js` の `touchInput` / `touchPressed` をPC入力から分離。短いタップをラッチし、タッチの解除でキーボード・マウス・パッドを解除しない。
- 意図したpointerupは既存の攻撃を発動する。pointercancel・キャプチャ喪失・ポーズ・回転・非表示・ホスト停止は `cancelTouchInput()` で取り消し、溜め突き・扇状弾・バスターを勝手に発射しない。
- 既存の移動速度、攻撃値、タイミング、背景・原画・PC操作を維持。追加画像・依存パッケージなし。新JSを通常配布とPlayablesの両方へ同梱、操作ガイドも英訳。
