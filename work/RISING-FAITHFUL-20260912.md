# 斬り上げを参考GIFに合わせて作り直した（2026-09-12）

ユーザー依頼：対空の参考GIFを渡され「これをそのまま忠実に再現して」。

結果：**技の構成そのものを作り直した。** 前の版は地上に留まって刃を振り上げるだけだったが、
参考は**しゃがみ → 飛び上がりながら炎の柱 → 滞空 → 落下 → 着地**という技だった。

## 1. 参考の読み取り

GIFはデスクトップの `ゲームAstra/qomsy77az2fd1.gif` にあった。120x208、88コマ、1コマ20ms。
コピーを `qa/rising-ref/reference.gif` に置いてある。全コマを展開して数値を測った。

| 区間 | コマ | 秒 | 内容 |
|---|---|---|---|
| 待機 | 0–8 | — | 立ち |
| しゃがみ | 8–12 | 0.08 | 体を沈め、炎が足元に溜まって前方の床を舐める |
| 上昇 | 14–40 | 0.52 | **飛び上がる。** 体を丸めて傾け、巨大な炎の柱を上前方へ |
| 収束 | 40–46 | 0.12 | 炎が細い渦に縮む |
| 落下 | 46–68 | 0.44 | 直立で降下。刃だけ小さく保持 |
| 着地 | 68–74 | 0.12 | 立ちへ戻る |

測った数値。

- **上昇量 92px**（足元 y=195 → 103）。体の高さが46pxなので**体2つ分**
- **前進 18px**（立ちの体の中心 x=32.5 → 50）
- **体の傾き：上昇中は垂直から30度。** 落下中は2〜5度（ほぼ直立）
- 炎は手から**約55px**、水平から**60度上前方**。幅26〜34px

傾きは色相で炎と体を切り分けて画像モーメントから出した。最初は炎を含めて41度と読み違え、
実際に描いたら寝すぎたので測り直している。

## 2. 合わせたもの

### 弧
`combat.rising` を追加。`lift:354` / `gravity:680` で上昇し、頂点を越えたら通常の重力1100に戻る。
**上昇に専用の重力を与えたのは、参考の0.52秒をそのまま出すため。** 通常重力だと0.41秒になる。

実測の対比。

| | 参考 | ゲーム |
|---|---|---|
| 頂点 | 92px | 89px |
| 頂点到達 | 0.52s | 0.58s（しゃがみ0.08s込み） |
| 着地 | 0.96s | 1.00s |
| 前進 | 18px | 23px |

途中で2つ既存の仕掛けを除外する必要があった。**ジャンプの高さ可変**（ボタンを離すと上昇を
切る処理）が上昇を食っていた件と、**横移動の摩擦**が前進を消していた件。どちらもこの技の
上昇中だけ外している。

### 姿勢
rig に2列足した。`spin`（腰を軸に図形ごと回す）と `lift`（足を自分の箱の床から持ち上げる）。
上昇中は spin 0.45（26度）で、rig自身の lean と合わせて参考の30度に寄せてある。

`lift` は最初**符号を逆に書いていて**、足を上げるつもりが下げていた。脚の届く距離27.25pxを
超えて膝のIKが破綻し、脚が横に開いた星型になっていた。符号を直して足を腰へ引き上げ、
足の左右幅も4/-3まで詰めたら、参考どおりの丸めた塊になった。

### 炎
`plume()` と `drawPlume()` を追加。手から生えて、上前方60度へ、長さ56・幅28。
根元が細く、中ほどで膨らみ、先端が軸を横切って巻く舌の形。外縁の暗い赤から橙・琥珀・
クリーム・白の5層で、後縁に火の粉を4つ置いている（乱数だとちらつくので固定位置）。
しゃがみの低い掃きも同じ炎で、短く寝かせただけ。

**この技の当たり判定は炎そのもの。** `blade()` は4段目のとき刃ではなく炎の軸を返す。
太い炎が細い刃の判定では見た目と合わないので、`combat.saberPad` で4段目だけ16pxに広げた。

### 当たり
炎は上昇中ずっと出ているので、0.14 / 0.27 / 0.40 / 0.53秒に**4回**噛む。
1発あたりの倍率は0.375で、合計6.75。通常の一振り4.5の1.5倍。

## 3. 合わせなかったもの

正直に3つ。

1. **炎の質感。** 参考はドット絵でぎざぎざに揺れる。こちらはベクター描画で滑らかな層。
   ぎざぎざを乱数で出すとフレームごとにちらつくので入れていない
2. **落下中の刃。** 参考は降下しながら小さな刃を上後方に保持する。こちらは技が0.62秒で
   終わり、そこから先は通常の落下姿勢になる。刃は出ていない
3. **絵そのもの。** 参考のスプライトは使っていない。このゲームの機体と配色で描き起こした

## 4. 検証

`npm test` 合格。モーション関連のテストを測り方ごと書き直した。

- **弧が参考と一致すること。** 頂点が92px±12、到達0.45〜0.70秒、着地0.85〜1.15秒、
  前進8〜34px。天井のない床を自動で探してから跳ばせている
- 斬り上げの到達高度が、その場で振る技より50px以上高いこと
- **その場で振る技では届かない高さのドローンを落とせること。** 炎の判定幅16pxも勘定に入れている
- 炎が4回噛み、順番どおりで、すべて上昇中に収まること。合計6.75
- 空中で出したときは追加の上昇が付かないこと（二段ジャンプにならない）
- ↑を離してから0.15秒以内、セイバーが先でも3フレーム以内なら出ること

release-check・browser-smoke 17項目・browser-mouse 12項目・saber-reach・9ステージ通し合格。

## 5. 調整するには

- 上昇量・上昇時間 → `game.js` の `combat.rising`（`lift` と `gravity`）
- 体の傾き・脚の丸め → `assets/saber-rig.js` の `keys[3]` の `spin` と `lift` の列
- 炎の長さ・太さ・形 → 同ファイルの `plume()` と `drawPlume()` の `tongue()`
- 噛む回数と時刻 → `combat.saberHitTimes[3]`、倍率は `combat.saberComboPower[3]`
- 判定の太さ → `combat.saberPad`
