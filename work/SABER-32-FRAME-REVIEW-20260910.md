# 32コマ照合と修正

参照: 添付image-1.gif、280×210、32コマ。全コマを取り出し、現在のゲーム素材と実際のAstraSaberRig.draw()から生成した32姿勢と比較。
qa/saber-faithful/compare-reference.cjs が描画取得。qa/saber-faithful/trace/phase-map.json が対応表。時刻メタデータが欠ける参考GIFに合わせてゲームの尺を推測変更せず、動作の節目で比較する。0.40秒はユーザーの後続指定に従って維持。

今回の修正:
- 4〜8・21〜26コマの半月を手元からの輪郭として定義。円の半径を回して作る方式を廃止。上から下へ白い面が回り込み、足元の湾曲へ変わる。
- 振りかぶりは右手を頭の後ろ側へ曲げ、刃を短く出す。大きく後方へ伸びていた初期の刃を除去。
- 縦斬りで左腕を後ろへ引く。二段目では胴の回転と共にその構えが解ける。
- 横薙ぎの平面を扁平にし、14〜15コマで大きく広がって16コマでは消える構成へ。
- 太い残像と細い刃が同時に別方向へ出る二重描画を抑制。

検証: npm test合格、左右606姿勢で有限値・腕の接続・待機／残像／収束を確認、描画エラー0。最新描画の最大手元移動はphase0.01あたり3.925未満。実描画で専用素材が胸領域のみを使い、カメラ向きヘルメットを使わないことも確認。

目視範囲: compare-0〜3.pngで全32姿勢を確認後、二段目の輪をさらに扁平化。最終current-15.pngを確認。比較合成画像の15付近は扁平化前のため再合成時にはcurrent-*.pngを使用する。

完全一致の達成を表明するには、体格が異なる中で頭・腰・両足の位置を同じ基準でさらに比較する必要がある。全コマ取得をやり直す必要はない。次の確認は一段目の振り抜き（5〜11）で、腰に対する頭の高さと前傾の差。テスト合格だけを完全模写の証明にしない。


体のランドマーク照合（2026-09-10）：参考6コマの腰(92,113)・首(111,85)・足首(112,151)/(45,153)・床163を読み取り。一段目の腰を3.5〜4px上げ、前傾と前足の張り出しを減らした。腰→首の傾きは参考0.596radに対し1.024→0.674rad、足首幅／腰高さ比は参考1.34に対し2.545→1.558へ改善。参考28コマも目視し、三段目は上体を少し起こして右手を前脚近くへ、左腕を体の前に畳む形へ修正。一段目は左腕を後ろへ引き、両者を区別。
検証：npm test、左右606姿勢、1203姿勢の脚幾何、実右クリック3段と合計20.25ダメージ、胸のみの素材切り出しすべて合格。描画エラー0。古い脚幅検証は全段40px以上という仮定を修正し、一段目30px以上・他40px以上に変更。膝が床へ折れる／脚が伸びすぎる検証は維持して合格。実測最大幅34.6/45.5/44.5px。詳細データqa/saber-faithful/trace/body-landmarks.json、更新動画qa/saber-faithful/combo-preview.mp4。
