## 英語紹介文

ASTRA // OVERDRIVE is a fast-paced 2D action game built around an eight-boss rush. Each mechanical boss has distinct attack patterns and telegraphed moves. Players combine a buster, three-hit saber combo, charged thrust, rising slash, charged fan burst, and precision dashes to defeat the bosses. The game includes adjustable difficulty, reduced screen motion, boss attack practice, per-boss records, and a continue option. It is playable directly in a browser with keyboard/mouse, gamepad, or touch controls.

A separate Playables build integrates the YouTube Playables SDK for loading notifications, host audio control, pause/resume, and cloud saves. Local regression and SDK host simulation tests pass. Official hosted certification and Android/iOS YouTube app testing remain pending.
