# ボスラッシュの「続きから」 — 2026-09-23（Opus 5.5）

ユーザー依頼「負けた時に続きから始める選択肢」。サブエージェント不使用。背景・キャラクター・操作・攻撃値は維持。

- 1体以上倒してから負けると、敗北画面の先頭に「続きから / ボス名」。負けたボスの登場演出から、HP満タンで再開。倒したボス（肖像のチェック）、経過時間（時計ごと）、被弾・弾消し・反撃数は引き継ぐ。1体目で負けた時は出ない（最初からと同じため）。
- 敗北画面の「この技を練習」から練習に入っても、練習のポーズ画面と結果画面に「連戦の続きから」。練習で負けても続きの地点は消えない。
- 続きの地点が消えるのは、新しい連戦の開始、8体連戦を最初から（Rキー含む）、タイトルへ戻った時、続きからを使った時。
- 記録：続きからのクリアは「CONTINUE ×回数 / 最速記録の対象外」と表示し、連戦の最速タイム・スコアには残さない（クリア済みの印だけ付ける）。結果画像にもCONTINUEを表示。ボス別戦績は1戦ずつの記録なので従来どおり残る。
- 撃破演出中に負けた場合は、倒しきったボスを数えて次のボスから。最後のボスを倒した後なら続きなし。

実装：mastery.js（saveRush / continueRush / rushContinueBoss / dropRushSave、retryとtoTitleで破棄）、ui.js（ボタン・記録の扱い・結果表示）、style.css（.defeat-note）。

検証：npm test成功（Node集計199件＝192件＋tests/rush-continue.test.cjs 7件）。ブラウザー：2体目で負け→続きから（TIDEBREAKER、HP8/8、WARDEN撃破済み、CONTINUE 1）→再び負け→技の練習→ポーズから連戦の続きへ（CONTINUE 2）→クリアで「CONTINUE ×2 / 最速記録の対象外」、runRecordsはclearedのみ。通しのクリアは従来どおりbestTime/bestScoreを記録。起動18・パッド29・マウス11成功、エラー0。人の手による通しプレイは未実施。
