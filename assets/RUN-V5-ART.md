# RUN V5 ART PROVENANCE

V5 keeps `player-run-v4.svg` and its embedded PNG unchanged. The rig uses measured cell-local masks for the body, arms, cannon, thigh, shin, and foot; no new raster artwork or image generation was used.

The run cycle is continuous at 0.38 seconds at full speed. Both legs use deterministic two-bone IK with lengths 11 and 13.5, Hermite swing timing, a half-cycle phase offset, and a grounded planted foot. The cannon and muzzle use the same phase transform, while the rear leg is rendered first with opaque shading.
